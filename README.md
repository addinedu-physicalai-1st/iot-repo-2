# 스마트 주차장 (Smart Parking Web App)

이 프로젝트는 Vite와 React를 사용하여 개발된 스마트 주차장 관리 웹 애플리케이션입니다.

## 🚀 시작하기

프로젝트를 로컬 환경에서 실행하려면 아래 단계를 따르세요.

### 1. 필수 조건

- [Node.js](https://nodejs.org/) (최신 LTS 버전 권장)
- npm (Node.js와 함께 설치됨)

### 2. 의존성 설치

터미널에서 프로젝트 루트 디렉토리로 이동한 후 다음 명령어를 실행하여 필요한 패키지를 설치합니다.

```bash
npm install
```

### 3. 개발 서버 실행

설치가 완료되면 아래 명령어로 로컬 개발 서버를 실행할 수 있습니다.

```bash
npm run dev
```

터미널에 표시된 로컬 주소(보통 `http://localhost:5173`)를 브라우저에서 열어 확인하세요.

---

## 🛠 사용 가능한 스크립트

| 명령어 | 설명 |
| :--- | :--- |
| `npm run dev` | 개발 서버를 실행합니다 (Vite). |
| `npm run build` | 프로덕션용으로 프로젝트를 빌드합니다. (`dist` 폴더 생성) |
| `npm run preview` | 빌드된 프로덕션 파일을 로컬에서 미리 보기 합니다. |
| `npm run lint` | 코드 린팅(Linting)을 수행합니다. |

## 📁 주요 구성

- `src/`: 애플리케이션 소스 코드
- `vite.config.ts`: Vite 설정 파일
- `package.json`: 프로젝트 정보 및 의존성 관리
- `init.sql`: 데이터베이스 초기화 스크립트 (사용 시 참고)
