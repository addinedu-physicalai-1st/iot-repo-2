0. 차단기 상태 기본값 이 현재 자동이면 차단기를 닫음 상태로 구성.

1. 입구 트리거에서 이벤트가 들어오면 입구 lpr 로 카메라를 판독하고 (트리거가 계속 발생된다면 판독시 하나의 같은 차량이라고 생각 = 판독 리스트) 서버에서 차량 정보를 조회하여 
   등록된 차량이 차단기가 열리고 트리거가 입구에서 출구쪽으로 트리거 잡히고,두개의 트리거가 끝나면 차단기가 닫히는 케이스 , DB 에 입차 리스트에 차량 등록정보 이미지를 저장 ,

2. 입구 트리거에서 이벤트가 들어오면 입구 lpr 로 카메라를 판독하고 (트리거가 계속 발생된다면 판독시 하나의 같은 차량이라고 생각 = 판독 리스트) 서버에서 차량 정보를 조회하여 
   등록하지 않은 차량(번호판) 일때는 등록되지 않은 차량으로 등록하고 차단기는 열리고 , 입구에서 출구쪽으로 트리거 잡히고,두개의 트리거가 끝나면 차단기가 닫히는 케이스 DB에 입차 리스트에 
   등록되지 않은 차량으로 1분지날때마다 과금 100 추가

3. 출구 트리거에서 이벤트가 들어오면 출구 lpr 로 카메라를 판독하고 (트리거가 계속 발생된다면 판독시 하나의 같은 차량이라고 생각 = 판독 리스트) 서버에서 현재 입차 차량정보를 찾아서
   등록된 차량이 출차 이면 DB 출차 정보를 업데이트 하고 이미지를 서버에 저장하고 출구 에서 입구쪽으로 트리거 잡히고 나서 두개의 트리거가 끝나면 차단기가 닫히는 케이스

4. 출구 트리거에서 이벤트가 들어오면 출구 lpr 로 카메라를 판독하고 (트리거가 계속 발생된다면 판독시 하나의 같은 차량이라고 생각 = 판독 리스트) 서버에서 현재 입차 차량정보를 찾아서
   등록되지 않은 차량이 출차 이면 DB 출차 정보를 업데이트 하고 LCD 로 Input RFID 메시지를 날리고, RFID 로 인식되면, 인식된 RFID 로 출차로 처리하고 이미지를 서버에 저장하고 출구 에서 입구쪽으로 트리거 잡히고 나서 두개의 트리거가 끝나면 차단기가 닫히는 케이스
   이케이스는 등록되지 않은 차량인데, 입주민이 카드를 임시로 방문자에게 대여하여 과금없이 출구를 지나가는 케이스,

우선 여기까지 테스트 케이스이고 이후는 다시 추가해서 케이스에 대한 기능을 구현하는걸로,
